# SuburbMates Web Application

This directory contains the Next.js public directory and owner flows. Read [`../docs/HANDOVER.md`](../docs/HANDOVER.md) before making changes.

## Checks

```bash
npm install
npm run lint
npm run build
```

The application uses Next.js App Router, Supabase server clients, and the Cloudflare OpenNext build path configured in `web/wrangler.jsonc`. Do not reintroduce Vercel deployment instructions.
